BENTO SLIDES

为制作一份演示文稿
您需要的一切。

bento/slides 是一份 HTML 文件，同时是文档、编辑器和演示器。打开它，编辑它，演示它 —— 它保存它自己。以下是 bento/slides 每部分工作的指南。

本页内容

快速开始 添加评论 平滑过渡 运动 & 特效 图表 & 表格 视频 & 音频 交互 演示 实时协作 保存 & 历史 用 AI 构建 键盘快捷键

1快速开始

一份 Bento 演示文稿就是一个 .bento.html 文件。在这里，无需安装任何软件，无需创建任何账户。

  • 在任何一款现代浏览器中打开文件 — 它直接进入编辑器界面。
  • 在 canvas 上编辑：点击以选择，拖动以移动，拖动 handle 以调整大小。双击文本以键入。
  • 用圆形的 ▶ 按钮（右下方）或F5放映 — 真正全屏，按下 → 以前进。
  • 用 ⌘S 保存。这个文件根据你的改动重写自己。当你编辑时，文件亦会自动保存。
整个应用就在文件里面。电子邮件发送它，把它存在云盘，或者放在 U盘里 — 无论谁打开它，都获得演示文稿以及编辑器，离线，永远。

2添加评论

点击顶部的工具栏可以为当前幻灯片添加元素：

T

文本

双击以编辑。键入**粗体**，*斜体*，`代码`或者- 要点 — 它们像您操作的那样调整格式。⌘B/⌘I/⌘U 亦可。

◇

图形

矩形，椭圆，三角形，以及线段。纯色或渐变填充、线条箭头和点、圆角、阴影。

▦

图像

在 canvas 上选择一份文件或者直接粘贴（⌘V）。图像嵌入在文件中，因此它保持自包含。

▶

媒体

视频和音频。短视频直接嵌入；对于长视频的话，可以粘贴一个网址（URL）让文件保持较小。更多见下。

▤

表格

一份真正的表格 — 在里面直接编辑单元格，用 Tab 切换单元格。预设了主题，仅需单击它就能将其转换为一张图表。

▥

图表

条形图，折线图，饼图，散点图，都由 Bento 自身的引擎绘制。可以可视化地编辑它或者将它链接到一张表格上。更多见下。

左侧面板显示您的幻灯片；右侧面板显示您所选元素的属性 — 位置，颜色，版面，效果。按下 [ 或 ] 以折叠任意一个面板。

3平滑过渡/变形(Morph) — 鲜明移动

这些元素会在它们的位置之间滑动，平滑切换大小，缓缓渐变颜色。这就是最佳的 Bento 演示文稿让人感到充满生机的诀窍。

    在连续的两张幻灯片间，给一个元素一个相同的名字 (id)，然后设置下一张幻灯片的切换效果为变形 — 当您切换页面时，

  • 最简单的方式：复制一张幻灯片，然后移动元素，或者对其重新着色，调整大小。这些共有的元素已经匹配 id 了，所以它们会自动平滑变形。
  • 在幻灯片的面板中，将一张幻灯片的切换效果设置为变形（morph）（或者复制一张已经使用变形效果的幻灯片）
  • 在每张幻灯片间给一个 logo 或标头设置相同的 id，当其他元素变化时，它能停在那里。

4运动 & 特效

那些电影般的细节——缓缓移动的照片、飞入的元素、递增的数字——都位于右侧面板的 演示设置 部分。选择一个元素，然后：

Ken Burns 效果——照片的缓慢移动

满屏图像上那种栩栩如生、有呼吸感的特质被称为 ambient motion（环境动效）。选择一张图片 → 演示设置 → 氛围 → 肯·伯恩斯，然后选择样式和节奏：

  • 漂移——无尽的、轻柔的平移与缩放，永远循环。这是默认设置，它能让封面照片像视频一样充满活力。
  • 缩小 / 放大——一次性的推拉效果，在幻灯片切入时渐渐稳定下来，用于刻意的视觉揭示。
  • 缩放 %（缩放百分比） 设置移动的范围；缩放秒数 设置持续时间——数值越大，移动就越缓慢s。

入场——元素如何出现

为元素添加 入场 动画，它将在幻灯片出现时执行动画——淡入淡出、上浮/下方淡入 或从任意边缘 滑入（slide）。有两个旋钮可以控制编排：

  • 顺序——错峰效果。序号越小越先出现；给几个元素分配相同的顺序，它们就会一起入场（逐层揭示图表）。
  • 入场秒数——速度。数值越小越干脆利落，数值越大越慵懒舒缓。

数字递增

为包含数字的文本元素开启 数字递增，它会在幻灯片切入时从 0 滚动到目标值——这是让统计数据更具冲击力的最简单方法。

另外两个运动技巧在别处：变形（§3）能让元素在幻灯片之间平滑滑动；以及 循环——行进的虚线或沿着你绘制路径移动的元素——能像环绕的圆点一样提供无尽的运动效果。

5图表 & 表格

图表

添加一个图表，然后在右侧面板设置它的外观：类型，系列，颜色，第二 Y轴，每个轴的最小/最大值，以及可编辑的数据表格。当您演示的时候，图表都是活动的 — 工具提示，缩放以及数据，当一个条形图变成饼图的时候平滑移动。

表格 → 图表，链接的

从表格面板将表格转换为图表，两者保持关联：编辑表格中的数字，图表会自动更新。非常适合显示数据和趋势并排的幻灯片。

6视频 & 音频

从工具栏添加媒体，然后选择一份视频或音频文件。Bento 采用了一种混合策略，因此你的文件永远不会变得臃肿：

  • 小片段内嵌在 .bento.html 中——完全自包含，支持离线播放。
  • 大文件：当片段较大时，Bento 会建议将其保留为链接——在面板中粘贴托管 URL，演示文稿就能保持小巧（只是播放时需要联网）。
  • 播放选项：控制条、循环、静音以及自动播放。自动播放仅在演示时生效，且浏览器要求视频静音才能自动播放。
  • 封面图（视频）：在播放前显示的一张静态图像。
提示：内嵌一个简短的 Logo 动画或 10 秒的演示片段；通过链接引用完整的录屏。将一个 2 分钟的视频作为数据内嵌，可能会让文件变成 100 MB，导致打开和保存极其缓慢。

7交互性

  • 链接与状态幻灯片：为元素添加一个指向其他幻灯片的链接。状态幻灯片是一种隐藏的变体，只能通过点击到达——方向键会跳过它，按 ← 返回父页面。非常适合“点击下钻查看”而不打乱线性叙事。
  • 悬停显示：当指针悬停在元素上时，就地替换内容。
  • 循环：一条行进的虚线，或者一个沿着你在画布上绘制的运动路径移动的元素——支持逐点变速。
  • 评论：使用 💬 工具（C）将评论固定在某个元素或位置。评论存在于文件中，但绝不会在演示或打印时显示。

8演示

  • 通过圆形的 ▶ 按钮（全屏）或旁边的小按钮（填充标签页，用于共享窗口）开始演示。F 切换全屏；Esc 结束放映。
  • 演讲者视图（S）：当前幻灯片、下一页、你的备注以及计时器——显示在一个单独的窗口中。
  • 激光笔（L）：切换虚拟激光笔。
  • 第二屏幕：在幻灯片面板的演讲者备注区域，启用一次“使用第二屏幕显示备注”（授予浏览器窗口权限）。之后按 S 就会自动将备注显示在你的另一块屏幕上。
  • 为每页幻灯片编写演讲者备注——它们随文件同行，并可作为演讲提示。

9实时协作

点击 Live 启动会话——此时文件本身就是邀请函。任何打开副本的人都能加入房间；编辑内容实时合并，离线更改也会在他们回归时重新合并。

  • 端到端加密：密钥就在你的文件里。中继服务器只能看到密文——它无法读取你的演示文稿。
  • 无账号，无云端：分享就是分享文件本身。
  • 通过 Live 弹出窗口设置你的名字，让你的光标有专属标识。“轮换密钥”可撤销旧副本的访问权限。

10保存与版本历史

  • ⌘S 就地重写文件（或者根据你的浏览器行为，首次会下载一份副本）。
  • 自动保存在你工作时提供本地安全网——如果标签页崩溃，重新打开时会提示你恢复。
  • 版本历史：保存 → 版本历史会列出本地较早的快照；你可以恢复任意一个（此操作可撤销）。
  • 密码保护在保存菜单中；只读和仅演示副本在共享菜单中，用于分发和私密演示文稿。

11用 AI 构建

因为文档就是文件内部的纯 JSON，任何 AI 都能编写或编辑演示文稿。把 .bento.html 丢进对话或项目（Cowork、Codex、Gemini、ChatGPT 项目）中并下达指令，或者让编码智能体直接处理磁盘上的文件。

智能助手应该首先阅读的指南是 bento.page/agents.md——它将你的素材映射到正确的功能，让你得到一份真正的演示文稿，而不是一堵文字墙。

bento-slides 技能

安装一次该技能，你的助手就能自动使用正确的功能创作演示文稿——它甚至能自行下载最新的 Bento 应用，因此你可以一次提问就从空文件夹得到一份完成并打开的演示文稿。每当你请求幻灯片，或直接运行 /bento-slides 时，它就会触发。

Claude Code — 从插件商店安装：

/plugin marketplace add nyblnet/bento
/plugin install bento-slides@bento

……或者作为普通的个人技能安装（无需重启；重新运行即可更新；使用 .claude/skills/… 将其作用域限定在单个项目内）：

mkdir -p ~/.claude/skills/bento-slides
curl -fsSL https://bento.page/skills/bento-slides/SKILL.md \
  -o ~/.claude/skills/bento-slides/SKILL.md

Claude.ai & Claude Desktop — 下载技能包（.zip），然后在 设置 → 技能 下上传。

ChatGPT · Codex · Gemini — 无需安装：将 bento.page/agents.md 附加到 ChatGPT 项目中，将其作为 AGENTS.md 放在你的演示文稿旁边供 Codex 使用，或者将其添加到 Gem 中。
